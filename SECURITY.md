# Security Policy

## Supported Branches

Security fixes are supported on `develop` (default) and `main`.

## Reporting a Vulnerability

Please report vulnerabilities privately using GitHub Security Advisories / private vulnerability reporting for this repository.

Do not open public issues for unpatched vulnerabilities. Include:

- A clear impact statement
- Reproduction steps
- A minimal proof of concept
- Suggested remediation (if known)

## Response Targets

- Initial triage: within 3 business days
- Status update: within 7 business days
- Remediation timeline: based on severity and exploitability
